AGY 令牌管理

在本机转换 AGY-CLI 导入 JSON，并直接导出已保存 Magpie 账号的 Refresh Token。

离线手动模式

导入 Refresh Token

RT → JSON

支持直接粘贴裸 RT，或粘贴含 refresh_token 的 JSON 自动提取。

脱敏 JSON 预览 格式有效 
{
  "token": {
    "refresh_token": "••••"
  },
  "auth_method": "consumer"
}

  1. 点击 复制导入 JSON（或下载 agy-account.json）。
  2. 在 Magpie 进入 供应商 → Antigravity（本地 agy CLI）→ 从文件导入账号，粘贴或选择文件确认。

导出 Refresh Token

本机账号
连接终端启动的本机扫描会话

在插件目录运行 node index.mjs --workbench 获取会话码。停止命令即可结束会话。

    手动选择账号目录

    默认目录：Windows %USERPROFILE%\.local\state\magpie-agy-bridge\accounts，macOS / Linux ~/.local/state/magpie-agy-bridge/accounts。可选择整个 accounts 目录或单个账号目录。

      所有令牌仅在本机处理，不会离开当前设备。复制内容含完整凭据，用完请及时清理剪贴板。
